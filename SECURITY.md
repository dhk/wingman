# Security policy

Please report suspected vulnerabilities privately through GitHub's
**Security → Report a vulnerability** flow for this repository. Do not open a
public issue containing an exploit, credential, capability URL, private user
data, or other sensitive detail.

Wingman's authoritative security and privacy rules are the
[Security and Privacy section of AGENTS.md](AGENTS.md#security-and-privacy) and
the product invariants in [VISION.md](VISION.md#product-invariants). The current
runtime trust boundaries, network egress, credentials, tunnel behavior, and
hosted-operator responsibilities are documented in
[docs/TRUST.md](docs/TRUST.md).

This project is actively developed and does not currently publish a guaranteed
security-support or compatibility window. Include the affected commit/tag,
deployment shape, impact, and the smallest safe reproduction you can provide.
