# Profile Interview Design — Research

Read order: `brief.md` → `findings/*.md` → `handoff-prompt.md` (if you're
picking this up as a copy-pasted prompt rather than in this repo) →
`synthesis.md` (once it exists).

**What this is.** A research pass on the three-category interview structure
(values / mission alignment / alignment of perspective) proposed 2026-07-27
as a refinement to `docs/PROFILE-BOOTSTRAP-DESIGN.md`'s interview modules —
see `brief.md` for the full context and the six questions this pass answers.

**Why findings stay independent until synthesis.** Each source (this
session, another tool, a person) researches the brief without reading the
others' findings first. Seeing another source's framing before you've done
your own pass anchors your search on their categories and their sources
instead of yours — the whole point of running more than one pass is to see
where independent researchers converge (real signal) versus where only one
of them found something (worth a second look, not automatic inclusion).
Only `synthesis.md`, written after every findings file is in, compares them.
