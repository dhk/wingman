# Research

Independent research passes commissioned to de-risk a design doc or RFC
before it leaves Draft — see `commission-research` in this repo's Claude
Code skills for the process this follows.

**Topics** (each a subfolder: `brief.md` → `findings/*.md` →
`handoff-prompt.md` → `synthesis.md`):

- [`career-ladder-rubrics/`](career-ladder-rubrics/README.md) — which career
  ladders are actually published, by whom, and under what redistribution
  terms; commissioned to resolve Q1 of `../QUESTION-BLOCKS-DESIGN.md`. Holds
  findings only — the brief was written in-conversation rather than
  committed, so this topic does not have the full four-file layout.
- [`profile-interview-design/`](profile-interview-design/README.md) — the
  three-category interview structure (values / mission alignment /
  alignment of perspective) proposed as a refinement to
  `../PROFILE-BOOTSTRAP-DESIGN.md`'s interview modules.

**Older, flat-layout research** (predates the subfolder convention above —
left as-is, not migrated):

- `RESEARCH-BRIEFING.md` (one level up) — the original competitive-landscape
  briefing.
- `competitive-landscape-2026-07-18-reality-check.md`,
  `competitive-landscape-2026-07-18-vs-the-field.md`,
  `comparator-rubric-2026-07-18.md` — its two independent findings passes.
- `DECISION-MEMO-2026-07-18.md` — the synthesis and decisions made from
